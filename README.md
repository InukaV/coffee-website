# Coffee Website

A responsive, single-page coffee shop website built with HTML and CSS to demonstrate web development fundamentals.

## Overview

This project showcases a modern, fully-responsive coffee shop website featuring multiple sections including hero, about, menu, testimonials, gallery, and contact information. It's designed to be both visually appealing and user-friendly across all device sizes.

## Features

- **Responsive Design** — Mobile-first approach that adapts seamlessly to all screen sizes
- **Interactive Navigation** — Fixed navbar with smooth scrolling to different sections
- **Hero Section** — Engaging banner with call-to-action buttons
- **About Us** — Company information with social media links
- **Menu Display** — Grid layout showcasing 6 menu categories with descriptions
- **Testimonials Carousel** — Interactive slider featuring customer reviews (powered by Swiper.js)
- **Gallery** — Visual showcase of coffee shop images
- **Contact Section** — Location, contact details, business hours, and contact form
- **Footer** — Social links and policy information

## Technologies Used

- **HTML5** — Semantic markup structure
- **CSS3** — Styling and responsive layout
- **Swiper.js** — Carousel/slider functionality for testimonials
- **Font Awesome 7.3.1** — Icon library for visual elements
